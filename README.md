## 学園について

音楽ゲーム学園は、音楽ゲームをめぐる知識や技術、文化を持ち寄り、蓄えていくためのコミュニティです。

音楽ゲームというジャンルには長い歴史があり、その間に膨大な知見が積み上がってきました。しかしその多くは個人の中に留まったまま失われたり、断片的に共有されるだけで散逸したりしがちです。誰かが確かめたことを次の誰かが引き継げる場所があれば、この文化はもっと豊かになる。学園はそうした発想から始まりました。

### どんな活動をする場所か

活動の形は問いません。譜面の構造を分析することも、上達のために身体の使い方を工夫することも、収録曲の背景や世界観を掘り下げることも、すべて学園が後押ししたい取り組みです。

学術的、という言葉から堅苦しさを感じる必要はありません。学園が想定しているのは、格式ばった研究発表の場ではなく、普段のプレイの延長線上にある関心を持ち寄り、それを言葉にして交わし合う場所です。「なんとなくこうだと思っていたこと」を確かめてみたい、あるいは誰かに伝えてみたい。その気持ちがあれば十分です。

### 大切にしていること

学園は、参加する一人ひとりを対等な存在として扱います。腕前や在籍年数によって発言の重みが変わることはなく、運営に携わる者も例外ではありません。

また、音楽ゲームに向き合う意志のある方であれば、どなたでも歓迎します。レートや段位、プレイ歴といった条件を設けるつもりはありません。

そして、この場所が一時の盛り上がりで終わらないことを願っています。関わる人が入れ替わっても営みが続いていくよう、記録を残し、仕組みを整えていきます。

これらの考え方は「学園憲章」として明文化しています。詳しくはサイト内の学園憲章のページをご覧ください。

## 技術的なこと

### 構成

静的サイトとして構築し、GitHub Pages で配信しています。

| 領域 | 使用技術 |
|---|---|
| フレームワーク | Next.js（App Router、静的エクスポート） |
| スタイリング | Tailwind CSS |
| コンテンツ管理 | Markdown（リポジトリ内で直接管理） |
| サイト内検索 | Pagefind（ビルド時にインデックスを生成） |
| 配信 | GitHub Pages（GitHub Actions で自動デプロイ） |

コンテンツはすべて `content/ja/` 配下の Markdown で管理しています。frontmatter はビルド時にスキーマ検証され、必須項目の欠落や書式の誤りがあるとビルドが失敗します。

### 開発

```bash
npm run dev        # 開発サーバー
npm run build      # ビルド（postbuild で Pagefind のインデックスも生成）
npm run lint
npm run typecheck
```

サイト内検索の動作確認には本番ビルドが必要です。`npm run build` の後、`out/` を配信して確認してください。

### 記事の予約投稿

記事の frontmatter に `publish` を書くと、その日時を過ぎるまで記事はサイト上に一切現れません。一覧から隠れるだけでなく、記事の HTML そのものが生成されないため、URL を直接開いても表示されず、サイト内検索にも出てきません。
