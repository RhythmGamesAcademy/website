# 音楽ゲーム学園 公式サイト

音楽ゲーム学園の公式ウェブサイトです。

[visit](https://rhythmgamesacademy.github.io/website/ja)

## 記事の予約投稿

記事の frontmatter に `publish` を書くと、その日時を過ぎるまで記事はサイト上に一切現れません。
一覧から隠れるだけでなく、記事の HTML そのものが生成されないため、URL を直接開いても表示されず、
サイト内検索にも出てきません。

```yaml
---
title: "音楽ゲーム学園公式HPを開設しました"
date: "2026-06-24"
publish: "2026-06-24T12:00+09:00"
category: "news"
excerpt: "学園の公式情報を発信するウェブサイトを公開いたしました。"
---
```

| 項目 | 意味 |
|---|---|
| `date` | 執筆日。内部的な記録であり、読者には表示しない |
| `publish` | 公開日時。この時刻を過ぎるまで記事はサイト上に存在しない。読者に表示する日付、および一覧の並び順にはこちらを使う |

`publish` は ISO 8601 形式で書き、**タイムゾーンオフセットを必ず付けます**（日本時間なら `+09:00`）。
ビルドは UTC 環境で走るため、オフセットの無い `2026-06-24T12:00` のような表記を許すと、
日本時間のつもりで書いた時刻が9時間ずれて解釈されてしまいます。書式が不正な場合はビルドが失敗します。

`publish` を省略した記事は公開済みとして扱われ、表示・並び順には `date` が使われます。

`date` と同じく、値は必ずダブルクォートで囲んでください。囲まないと YAML が日付型として解釈し、ビルドが失敗します。

予約投稿の対象は `content/ja/articles/` 配下の記事だけです。学園憲章や固定ページには適用されません。

### 公開されるタイミング

本サイトは静的エクスポートで GitHub Pages に配信されており、サーバーは存在しません。
公開判定はビルド時にしか行えないため、**記事は「公開日時を過ぎたあと最初に走ったビルド」で公開されます。**
指定時刻ちょうどに公開されるわけではありません。

- 定期ビルドを毎日 **日本時間 12:00**（03:00 UTC）に実行しています（`.github/workflows/nextjs.yml` の `schedule`）。
  GitHub Actions の定期実行は混雑状況によって遅延することがあります
- **`publish` の時刻が定期ビルドの時刻より遅い場合、公開は翌日になります。** 例えば `publish` に
  その日の 18:00 を指定した記事は、同じ日の 12:00 のビルド時点ではまだ未公開と判定され、
  翌日 12:00 のビルドで初めて公開されます。当日中に公開したい場合は、`publish` を 12:00 より前の
  時刻にするか、下記の手動実行を使ってください
- すぐに公開したいときは、GitHub の Actions タブから `Deploy Next.js site to Pages` ワークフローを
  手動実行（`workflow_dispatch`）できます。main への push でも同じくビルドが走ります

### 注意

- **GitHub は、60日間コミットの無いリポジトリの定期実行ワークフローを自動的に無効化します。**
  更新が長期間止まると定期ビルドが止まり、予約投稿が公開されなくなります。無効化された場合は
  Actions タブから手動で再有効化してください
- `content/ja/hero-slides.json` の `linkUrl` が未公開記事を指していると、公開日時が来るまで
  リンク切れになります。ビルド時に `[hero-slides]` で始まる警告をログへ出しています
- 公開日時を過ぎたかどうかはビルド実行時の現在時刻で判定します。`npm run dev` でも同じ判定を行うため、
  未公開記事はローカルでも表示されません（プレビュー用のフラグはありません）
